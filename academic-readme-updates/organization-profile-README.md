## Overview

This organisation contains software engineering projects developed during my Computer Engineering degree at ISEC.

The academic repositories are kept separate from my main GitHub profile so that university work can be preserved without mixing it with current professional, freelance and product development.

## Repository Types

### Portfolio Versions

Public repositories may include improvements made after the original academic submission.

These versions are prepared for technical and portfolio review while preserving the academic origin of each project.

### Original Submissions

Private repositories ending in `-archive` preserve original academic submissions when appropriate.

They are retained for historical reference and should not be interpreted as current production software.

## Academic Principles

Public portfolio versions should:

- clearly identify their academic origin
- distinguish later improvements from original submissions
- avoid publishing credentials or private student information
- document architecture and engineering decisions accurately
- avoid claiming features that are not implemented
- preserve contributor attribution
