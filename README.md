## Academic Projects — ISEC

These four projects were developed in an academic context at the Instituto Superior de Engenharia de Coimbra. Their portfolio repositories are presented as academic engineering work, not as personal or commercial products.

### 1. [Distributed Quiz Platform](https://github.com/DaviGama08/distributed-quiz-platform-isec)

Fault-tolerant Java and JavaFX quiz platform with TCP/UDP discovery, primary-backup replication, automatic failover, concurrent clients and SQLite persistence.

`Java` · `JavaFX` · `TCP/UDP` · `Multicast` · `SQLite` · `Maven`

### 2. [JavaFX Chess](https://github.com/DaviGama08/javafx-chess-isec)

Desktop chess application demonstrating rule modelling, MVC-oriented separation, Memento-based undo/redo, persistence, testing and reusable object-oriented patterns.

`Java` · `JavaFX` · `MVC` · `Memento` · `JUnit` · `Maven`

### 3. [SurpriseMe Gift Assistant](https://github.com/DaviGama08/surpriseme-gift-assistant-isec)

JavaFX desktop application for managing recipients, events and gift history and producing personalised gift and card-message suggestions.

`Java` · `JavaFX` · `Jackson` · `JUnit` · `Maven`

### 4. MyMedia Marketplace

Full-stack multimedia marketplace composed of a Blazor frontend, REST API, back office and shared Web/MAUI components, with Identity, JWT and Entity Framework Core.

The portfolio repository has been renamed to `mymedia-marketplace-isec` but remains private while tracked configuration and credential material are remediated. A public link will be added only after the security review passes.

`C#` · `.NET` · `Blazor` · `REST API` · `Entity Framework Core` · `SQL Server`
